# The Sleepless Shelf

ネット活動用のキャプション作成ツール

## 📝 概要

このプロジェクトは、ネット活動で使用するキャプション（字幕・キャプテキスト）を簡単に作成するためのツールです。HTML/JavaScriptで実装されており、ブラウザで直接使用できます。

## 🎯 主な機能

- キャプション作成
- テキスト編集
- プレビュー表示
- エクスポート機能

## 🛠️ 使用技術

- **HTML5**
- **JavaScript**
- **CSS3**

## 📦 インストール

```bash
git clone https://github.com/knkneco/the.sleepless.shelf.git
cd the.sleepless.shelf
```

## 🚀 使用方法

1. ブラウザで `index.html` を開く
2. キャプション内容を入力
3. プレビューで確認
4. エクスポート
